# v0.7.1 Analytics and Skill-Gap Fix Report

Date: 2026-10-02

## Problem observed

The Analytics page only displayed sources that already had rows in `live_jobs`. As a result, Arbeitnow and Jobicy appeared, while Ashby, Lever and SmartRecruiters disappeared completely when no employer targets had been configured or when a configured target returned zero relevant jobs.

That made "supported source" and "currently collected source" look like the same thing.

The Skill Gap page also counted missing skills from the flattened job-skill list rather than using the structured required/preferred requirements introduced in the v0.7 Match Layer.

## Fixes

### Complete source analytics

The dashboard API now returns `market.source_analytics` for:

- Arbeitnow
- Jobicy
- Ashby
- Lever
- SmartRecruiters
- any additional imported/external sources found in PostgreSQL

Each source reports:

- source mode
- status
- configured target count
- enabled target count
- total stored jobs
- CV-relevant stored jobs
- last stored sync timestamp

Direct employer ATS statuses distinguish:

- `not configured`
- `disabled`
- `configured`

Arbeitnow and Jobicy remain `active` public feeds.

### Analytics UI

Analytics now shows all supported sources even when the current count is zero.

The page also shows:

- total tracked jobs
- CV-relevant jobs
- ATS source families configured
- ATS jobs collected
- source status badges
- employer-target configuration counts
- a **Configure ATS** shortcut to Settings

This prevents a zero-count ATS integration from silently disappearing.

### Dashboard source summary

The dashboard header now shows the number of configured ATS source families, for example:

```text
ATS sources configured: 1/3
```

### Structured Skill Gap

Skill gaps are now calculated from the v0.7 Match Layer:

```text
missing required skills
+
missing preferred skills
```

The UI shows:

- total relevant jobs containing the gap
- number where the skill is required
- number where it is preferred
- whether the gap is required-heavy or preferred-heavy
- improvement action

This is more useful than counting every extracted keyword in the market.

## Important source behavior

Ashby, Lever and SmartRecruiters are employer-specific ATS collectors. Supporting the provider does not automatically create jobs.

A company target must first be added in:

```text
Settings
→ Direct employer ATS collectors
```

Then:

```text
Refresh Current Jobs
```

will fetch that employer's currently published technical roles.

Therefore an Analytics row such as:

```text
Ashby
0 jobs
not configured
```

means the integration is available but no Ashby employer board has been configured yet.

## Tests

Added backend coverage for:

- showing supported sources with zero current jobs
- Ashby configured vs Lever not configured states
- structured required/preferred skill-gap counts

GitHub Actions validates backend tests and frontend syntax after the update.
