# Job-specific CV drafts

On a job card, choose **Tailor CV**, select an uploaded CV and review the
suggestions. The editable draft keeps the source text and adds job-relevant
terms and snippets found in that CV. A term mentioned in a CV is not necessarily
a skill the candidate possesses; the user needs to review the context.

Edit the draft, check the whole document and use **Download editable Word CV**.
The output is a separate DOCX. It does not replace the stored CV and is not
attached automatically; upload it explicitly when applying. Creating the draft
does not submit an application or send any message.

The source is extracted text. A PDF with multiple columns may extract in an
unexpected order, so check names, dates, sections and formatting carefully.
Manual edits are not automatically verified. This deterministic feature does
not require an AI model and does not claim to predict hiring outcomes.
