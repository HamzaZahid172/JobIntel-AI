# v0.8 Conversion Engine Upgrade

This release shifts JobIntel AI from an ATS/readiness dashboard toward an application-conversion assistant.

## Why this change

A generic ATS score can show that a CV is readable, but it does not explain why real applications are rejected. The v0.8 changes focus the product on application quality, job selection and measurable outcomes.

## Changes

### 1. Language-level gating

Job matching now compares explicit CV language levels with job requirements. A CV that says German A2 no longer passes a role requiring German B2/C1 simply because the word "German" appears in the CV.

### 2. Target-role constrained job feed

The default relevant-job feed now respects the profile's configured target roles. Jobs outside those role families are removed when they do not overlap the user's chosen direction.

Default filtering also removes:
- jobs with hard blockers;
- jobs below 65% overall match;
- jobs without meaningful skill overlap.

This intentionally favors quality over application volume.

### 3. Application conversion diagnostics

The dashboard now reports:
- positive-response rate;
- interview rate;
- rejection rate;
- count of high-match rejections;
- actionable diagnosis based on tracked outcomes.

If high-match jobs are still rejected, JobIntel now identifies this as a positioning/tailoring problem rather than recommending more generic ATS optimization.

### 4. Greenhouse employer collector

Greenhouse public job boards are now supported as a configurable direct-employer ATS source alongside Ashby, Lever and SmartRecruiters.

Use the Greenhouse board token as the collector identifier.

### 5. Dashboard UI

The previous performance panel is upgraded to an Application Conversion panel so the most important question is visible immediately: are applications producing positive responses?

## Recommended workflow

1. Keep target roles narrow and current in Settings.
2. Refresh current jobs.
3. Prioritize roles at 80%+ match when possible.
4. Do not apply to jobs with hard language or requirement blockers.
5. Track every submitted application and update its status.
6. Review conversion diagnostics after each 5-10 applications.
7. If high-match roles are rejected, tailor CV summary and first-page bullets to the job's top requirements before sending more applications.
